# SWIM frontend

Vite + React + TypeScript UI for the SWIM protocol simulator.

Install and run from this directory:

```powershell
copy .env.example .env
npm install
npm run dev
```

The UI expects the FastAPI backend at `VITE_API_BASE_URL` (default `http://127.0.0.1:8000`).

See the repository root README for the full local workflow.
